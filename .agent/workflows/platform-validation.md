## 安装与权限

- 从对应系统的 CI 产物安装，检查中文界面和卸载；Mac 检查 app bundle 的最低系统版本与权限描述。
- 首次麦克风授权、拒绝后提示、在系统中重新授权后恢复。
- Mac 系统音频录制首次授权 / 拒绝 / 重启恢复；Windows 隐私设置禁用麦克风的提示。
- 检查 AppData / Application Support 下凭据与数据库的位置和访问控制；确认日志和前端事件无凭据。

## 输入与输出

- 单麦克风、双麦克风、系统音频、文本分别使用，再同时使用；确认转写保留来源。
- 测试 44.1 / 48 kHz 麦克风，以及 16 / 24 / 44.1 / 48 kHz 输出设备的重采样。
- 耳机与虚拟声卡同时输出；在播客软件中接收虚拟声卡，不形成输入回送。
- 系统采集不重复转写本应用自身播放；检查文字 + 语音、仅文字、仅语音三种组合。
- 开始前设备消失应阻止启动；会话中拔出输入或某个输出应显示具体错误，其他正常来源继续。

## 会话与服务

- 用不同的自定义提示词验证职责变化，不依赖预设场景；运行中改提示词在下一次请求生效。
- 有效人声打断、手动立即停止、暂停中断上传和播放；迟到的模型结果不得重新发声。
- 语音输出状态直到播放结束；长回复缓冲有上界，无持续内存增长。
- 无效文本 Key、无效语音 Key / Token、错误资源 ID、无音色授权、配额不足、断网和网络恢复。
- 旧版与新版语音鉴权分别验证；记录账号使用的实际资源和模型，但凭据只写入私有 `.env`。
- 会话历史查看与删除，助手删除级联，异常退出后重启的历史状态。

## 延迟与稳定性记录

在耳机环境运行至少 30 分钟，记录语句结束到文字出现、首段语音播放的 p50 / p95，以及 CPU、内存、掉帧和误打断情况。至少包含中文对话、多来源同时说话和长时间静音。将实际结果写入当日 milestone；不把尚未测量的目标当作结论。
